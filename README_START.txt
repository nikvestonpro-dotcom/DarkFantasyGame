ЧТО ЭТО
Godot-проект с настроенным PS1-рендером и почищенными ассетами
(удалено ~1,4 ГБ дублей и мусора, спасены факелы, трон, таверны, фонарь).

КАК ОТКРЫТЬ (5 шагов)
1. Распакуй архив целиком в любую папку.
2. Запусти Godot 4.7 (окно со списком проектов).
3. Вкладка «Import» справа → кнопка «Browse» → выбери папку DarkFantasyGame
   (внутри лежит project.godot) → «Import & Edit».
4. Жди импорта: 5–15 минут (полоса прогресса внизу). Не закрывай Godot.
5. Слева-внизу панель «FileSystem» → папка test → двойной клик по
   pixel_test.tscn → нажми F5.

ЧТО ДОЛЖНО ПОЛУЧИТЬСЯ
Тёмный фон, серо-синий куб медленно вращается, пол растворяется в холодном
тумане, рёбра ступенчатые и пиксельные.
Это внутренний рендер 480x270, растянутый на весь экран — сердце PS1-стиля.

ЕСЛИ GODOT ПРЕДУПРЕДИТ О ВЕРСИИ ПРОЕКТА — жми ОК, всё будет работать,
но напиши ИИ, какая у тебя версия (Help → About в редакторе).

КАК ЗАЛЕТЬ В ТВОЙ GITHUB (по желанию, один раз)
1. Открой терминал в распакованной папке DarkFantasyGame:
   Windows: папка открыта в Проводнике → щёлкни адресную строку →
   напиши cmd → Enter.
2. Вставь по одной строке (после каждой жми Enter):
   git init
   git branch -M main
   git remote add origin https://github.com/nikvestonpro-dotcom/DarkFantasyGame.git
   git add -A
   git commit -m "Stage 0: cleanup + Godot project with PS1 render"
   git push -f origin main
Это заменит репозиторий чистой версией (старая история с дублями не нужна).
Если git попросит логин — входи через браузер/GitHub Desktop.

СТРУКТУРА ПРОЕКТА
  project.godot          — настройки проекта (GL Compatibility, окно 1280x720)
  test/pixel_test.tscn   — тест PS1-рендера (вращающийся пиксельный куб)
  assets/models/packs    — 9 паков в PS1-стиле (замок, бочки, лес, оружие)
  assets/models/kay_*    — персонажи KayKit (kay_Knight — будущий герой)
  assets/models/props    — факелы, трон, фонарь, знамёна
  assets/models/houses   — дома и таверны
  assets/models/trees    — деревья
  assets/textures/       — 2K-фото-текстуры (сырьё для конвейера PS1;
                           Godot их НЕ импортирует — стоит файл .gdignore)
  assets/_raw/           — сырьё: Delven-текстуры, анимационные паки
                           (тоже с .gdignore)
  PROJECT_MASTER_PLAN.md — конституция проекта (этапы, правила, стиль)
