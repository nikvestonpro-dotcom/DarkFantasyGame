HOLLOW MOON — Запрос №2 «Вайб-скрин: Ночь над замком»
═══════════════════════════════════════════════

ЧТО ЭТО
Играбельный вайб-скрин: ночная равнина, дорожка с факелами, силуэт
готического замка на скале в тумане, огромная бледная луна, туманность
и мерцающие звёзды (палитра собрана по твоим фото-референсам).
Плюс первое управление: рыцарь ходит, бегает, прыгает и ЛЕТАЕТ.
Рендер честный PS1: 426×240, растяжение ×3, Nearest.

КАК ОТКРЫТЬ
1. Распакуй архив целиком (или поверх старой папки — структура та же).
2. Godot 4.7 → Import → выбери папку DarkFantasyGame → Import & Edit.
3. Первый импорт: 5–15 минут (полоса внизу). Не закрывай Godot.
4. F5 — сразу запустится сцена вайб-скрина.

УПРАВЛЕНИЕ
  WASD     — движение (физическая раскладка — на русской тоже работает)
  Мышь     — камера
  Shift    — бег (в полёте — ускорение)
  Space    — прыжок (в полёте — вверх)
  C        — вниз в полёте
  F        — полёт вкл/выкл (взлети и облети замок!)
  V        — вид от 1-го / 3-го лица
  ESC      — показать курсор (щёлкни по окну — захватить снова)

ЧТО ПОСМОТРЕТЬ (ГАТЕТ ЗАПРОСА №2)
- Замок-силуэт на скале наполовину в тумане, луна слева над ним.
- Пиксели крупные и чёткие, картинка нигде не «мылит».
- Прогуляйся по дорожке; взлети (F) — вид на замок сверху душевный.
- FPS: нижняя панель редактора → Debugger → Monitors → FPS (цель 60).
- Ничего фотореалистичного и выбивающегося из стиля быть не должно.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ (это не баги)
- Факелы пока БЕЗ огня — пламя и тёплые отсветы в Запросе №3.
- Если рыцарь идёт «спиной вперёд» — напиши: разворот на одну строку.
- Сквозь стены замка можно пройти — коллизии стен на следующем этапе.

СТРУКТУРА (что нового с Этапа 0)
  scenes/vibe/vibe_screen.tscn — сцена вайб-скрина (главная, F5)
  shaders/night_sky.gdshader   — процедурное небо: луна, звёзды, туманность
  scripts/player_controller.gd — игрок: ходьба/бег/прыжок/полёт
  scripts/sky_dome.gd          — купол неба следует за камерой
  РЕФЕРЕНСЫ РАБОТЫ/            — твои фото (по ним сделана палитра)
  test/pixel_test.tscn         — тест конвейера Этапа 0 (куб)
  assets/                      — ассеты, как после чистки Этапа 0
