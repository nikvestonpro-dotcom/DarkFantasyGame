ЧТО СЛОМАЛОСЬ
--------------
В папке assets/textures/ оказался файл .gdignore — пустой файл,
имя начинается с точки. Из-за него Godot ПОЛНОСТЬЮ игнорирует
папку textures: текстуры не импортируются, и скрипт
village_builder.gd не может загрузить текстуру дыма труб
(puff_diff.png) — отсюда две ошибки на строке 185 и отказ
запуска. Файл попал туда при распаковке пака ассетов
(коммит «тут новый персонаж и новый пак»).

ЛЕГЕНДА: .gdignore есть и в других местах (assets/_raw/,
psx-dungeon-kit-free/..., psx-medieval-village-kit-free/...) —
эти НЕ трогай, они нужны. Удалить надо ТОЛЬКО один:
  assets/textures/.gdignore


ШАГ 1 — УДАЛИ ВРЕДИТЕЛЯ (самое важное!)
---------------------------------------
1) Полностью закрой Godot.
2) Открой папку проекта в проводнике (где лежит project.godot).
3) Зайди в assets → textures.
4) Удали файл .gdignore (имя начинается с точки!).
   Если его не видно: проводник → Вид → галочка «Скрытые элементы».

Или одной командой в командной строке Windows (запусти cmd
в папке проекта):
  del "assets\textures\.gdignore"


ШАГ 2 — ЗАЛЕЙ ФАЙЛЫ ИЗ ЭТОГО АРХИВА
-----------------------------------
1) Скачай и распакуй этот ZIP.
2) Выдели ВСЁ внутри (Ctrl+A) и скопируй в папку проекта
   (туда, где project.godot) — С ЗАМЕНОЙ файлов.
   Папки scripts, shaders, scenes, assets сольются с существующими.
   Если Windows спросит «заменить?» — отвечай «заменить файлы».
В архиве: все скрипты и сцены (актуальная версия с GitHub),
текстуры луны/дыма/неба, 27 моделей природы — на случай,
если что-то из этого потерялось у тебя локально.


ШАГ 3 — ОЧИСТИ КЭШ ИМПОРТА
---------------------------
В папке проекта удали ЦЕЛИКОМ папку .godot
(это просто кэш — Godot пересоздаст её сам).
Это обязательно: кэш сейчас неполный, потому что папка
textures игнорировалась.


ШАГ 4 — ЗАПУСКАЙ
-----------------
1) Открой проект в Godot 4.3.
2) Первый запуск будет дольше обычного — идёт переимпорт
   всех ресурсов. Подожди, пока прогресс в правом нижнем
   углу закончится.
3) Нажми F5 — игра должна запуститься.

ПРОВЕРКА: открой в редакторе scripts/village_builder.gd —
у строки 185 (const PUFF_TEX := preload...) красных ошибок
быть не должно.


ШАГ 5 — ГИТХАБ (чтобы баг не вернулся)
---------------------------------------
Тот же .gdignore лежит и в репозитории на GitHub. Зайди
на github.com → nikvestonpro-dotcom/DarkFantasyGame →
assets → textures → .gdignore → Delete file → Commit changes.
Иначе при следующем скачивании репозитория баг вернётся.


ЕСЛИ ЧТО-ТО ВСЁ РАВНО НЕ ТАК
-----------------------------
Пришли скриншот ошибки — я посмотрю. Проверено: эта версия
запускается в Godot 4.3 без единой ошибки скриптов.
